## Brand & Style

This design system synthesizes high-velocity cyberpunk telemetry with the rigorous, minimal clarity of enterprise developer tooling. Purpose-built for technical portfolios, mobile CV presentations, and real-time automation control surfaces, it frames human-AI engineering achievements as verified, mission-critical operations.

### Personality & Emotional Response
The interface evokes absolute operational command, precision, and technological foresight. It replaces ornamental noise with architectural depth, micro-metric readouts, and surgical signal luminescence. The user feels as though they are piloting an autonomous runtime engine rather than browsing a static portfolio.

### Visual Design Movement
A fusion of **Enterprise HUD Glassmorphism** and **Technical Neo-Brutalism**:
- **Backdrop Geometry:** Deep void-black canvases layered beneath micro-diffused glass panels.
- **HUD Telemetry:** Fine structural lines, precision bounding indicators, coordinate tags, and monospaced diagnostic labels framing interactive modular panels.
- **Controlled Luminescence:** Cyan and neural teal emissive accents used strictly to signal active states, system health, execution targets, and critical narrative milestones.

## Colors

The color architecture is calibrated for OLED contrast, deep ocular focus, and visual hierarchy.

- **Primary (`#06B6D4` - Neural Teal):** The anchor for active telemetry, primary interactive surfaces, focal system states, and structural focus rings.
- **Secondary (`#00F2FE` - Cyber Cyan):** High-energy emission color reserved for headline emphasis, current execution points, slide progression indicators, and active glows.
- **Tertiary (`#10B981` - Hyper Emerald):** Used for live system health, automation success metrics, verified uptime badges, and positive benchmark comparisons.
- **Neutral (`#0B111B` - Void Surface):** The bedrock background canvas, scaling into `#06090E` for true canvas depth, and stepping up to semi-translucent `#111A29` for elevated HUD panels.

### Surface Tiers
- **Canvas Base:** `#06090E` (Absolute void, grounding mobile viewport bounds).
- **Surface Level 1 (Panels & Decks):** `rgba(11, 17, 27, 0.72)` with structural borders set to `rgba(6, 182, 212, 0.16)`.
- **Surface Level 2 (Interactive Modules):** `rgba(17, 26, 41, 0.85)` with accent outlines `rgba(0, 242, 254, 0.28)`.
- **Telemetry Text / Signals:** `#E2E8F0` for primary content, `#94A3B8` for secondary documentation, and `#475569` for inert grid metadata.

## Typography

The typographic system balances futuristic architectural geometry with developer-grade clarity.

- **Headline Hierarchy (`Sora`):** Chosen for its sculpted geometric forms, balanced apertures, and modern forward momentum. Used across main deck headers, key milestone titles, and metric figures.
- **Body & Telemetry Hierarchy (`Geist`):** Delivers clean readability for architecture breakdowns, system logs, code annotations, and interface controls. 
- **Telemetry Labels:** Always rendered uppercase with open tracking (`letterSpacing: 0.08em` to `0.12em`) to mirror aerospace HUD standards.

## Layout & Spacing

The layout model is anchored on an adaptive **8-point HUD grid** tailored for mobile-first CV decks and expanded desktop monitors.

### Viewport Structures
- **Mobile Deck Architecture (< 640px):** Single vertical slide frame with strict `1rem` margins and `100dvh` locking. Internal module cards utilize `space-md` gaps with contextual micro-scroll containers for technical stack breakdowns.
- **Tablet / Expanded Mobile (641px - 1024px):** Dual-column layout allocating 40% width to fixed HUD status and telemetry parameters, and 60% to project interactive cards.
- **Desktop Console (> 1024px):** Fixed 12-column grid capped at 1200px container width. Margin defaults to `1.5rem` or auto-centered balance, utilizing `gutter` spacing of `1rem`.

### Spacing Rhythm
Vertical cadence relies strictly on tokenized steps: metadata stacks use `space-xs` (4px), list modules use `space-sm` (8px), card interior pads consume `space-md` (16px), and card-to-card deck stacks advance at `space-lg` (24px).

## Elevation & Depth

Visual hierarchy does not use soft skeuomorphic drop shadows. Instead, depth is achieved through **optical luminosity**, **refraction**, and **spectral edge delineation**.

### Surface Depth Layers
1. **Zero Plane (Backdrop Canvas):** Deep void (`#06090E`) with an optional 32px radial grid matrix set at `3%` opacity in `#06B6D4`.
2. **HUD Panel Plane (Deck & Cards):** Translucent fill (`rgba(11, 17, 27, 0.72)`) backed by `16px` to `24px` backdrop blur (`backdrop-filter: blur(16px)`). Bound by a hairline border: `1px solid rgba(6, 182, 212, 0.18)`.
3. **Elevated Focal Layer (Modals & Active Telemetry Cards):** Translucent fill (`rgba(17, 26, 41, 0.90)`), backdrop blur `24px`, bound by `1px solid rgba(0, 242, 254, 0.45)` paired with an inner edge specular glow (`inset 0 1px 0 0 rgba(0, 242, 254, 0.3)`).

### Emissive Glow Architecture
- **Passive HUD Edge:** `0 0 0 1px rgba(6, 182, 212, 0.15)`.
- **Active State Glow:** `0 0 16px -2px rgba(6, 182, 212, 0.35), 0 0 0 1px rgba(0, 242, 254, 0.5)`.
- **System Alert / Execution Pulse:** Dual-ring glow using `0 0 12px rgba(16, 185, 129, 0.4)`.

## Shapes

The interface embraces a **Soft / Precision Engineered** shape language (`roundedness: 1`). Elements favor tight, surgical corners that preserve an intentional instrument-panel feel without harsh brutish angles.

### Shape Geometry Rules
- **Base Element Corner Radius:** `0.25rem` (4px) across inputs, micro tags, status beacons, and buttons.
- **Cards & Primary Modules (`rounded-lg`):** `0.5rem` (8px), creating defined, technical containers.
- **Large HUD Surfaces & Decks (`rounded-xl`):** `0.75rem` (12px), softening the outer frame borders on handheld mobile viewports.
- **HUD Chamfering:** Interactive preview frames and image headers may incorporate subtle 45-degree corner notches (4px clip-path) at the top-right corner to emphasize HUD diagnostic cards.

## Components

### Buttons
- **Primary Cyber Button:** Solid fill of `#06B6D4` with `#06090E` bold typography (`label-sm`). Outer edge carries an ambient emission halo (`0 0 12px rgba(6, 182, 212, 0.4)`). Active tap scales to `0.98`.
- **Secondary Ghost HUD Button:** Background of `rgba(6, 182, 212, 0.06)`, border `1px solid rgba(6, 182, 212, 0.32)`, text in `#00F2FE`. Hover or focus triggers border shift to `#00F2FE` with an ambient glow.

### Interactive Project Cards
- Crafted with backdrop glass (`rgba(11, 17, 27, 0.75)`), `8px` corner radius, and `1px` structural outline.
- Includes a top telemetry header bar: micro-monospaced system index (e.g., `[SYS.ACT-01]`), dynamic runtime badge, and latency/model tag.
- Expanding actions unveil architecture diagrams and benchmark metrics with smooth height transitions and subtle cyan gradient sweeps (`linear-gradient(180deg, rgba(6, 182, 212, 0.08) 0%, transparent 100%)`).

### HUD Chips & Status Badges
- **Uptime / Verified Chip:** Background `rgba(16, 185, 129, 0.08)`, border `1px solid rgba(16, 185, 129, 0.3)`, text `#10B981`. Features a pulsing `4px` live status indicator pip.
- **Skill / Model Tag:** Background `rgba(11, 17, 27, 0.9)`, border `1px solid rgba(148, 163, 184, 0.15)`, text `#94A3B8`.

### Slide Pagination Indicators
- Mobile CV deck uses segmented horizontal HUD track bars.
- Inactive slides appear as dimmed, slim hashes (`2px` height, `rgba(148, 163, 184, 0.25)`).
- Active slide expands dynamically into an illuminated neon cyan bar (`0 0 8px #00F2FE`) paired with an overlaid numeric coordinate tag (`e.g., 03 / 08`).

### Telemetry Lists & Key-Value Trees
- Monospaced metric keys (`telemetry-mono`) in `#64748B`, dot-leader guide lines spanning to bold `#E2E8F0` values.
- Inter-item row borders set to fine translucent strokes (`rgba(255, 255, 255, 0.04)`).

### Input Fields & Terminal Search
- Inset dark background (`#06090E`), `4px` radius, hairline border `rgba(6, 182, 212, 0.2)`. Focus transitions border to `#00F2FE` with an electric glow ring (`0 0 0 1px #00F2FE, 0 0 10px rgba(0, 242, 254, 0.25)`). Prefix icons utilize terminal carats (`>`).

### Checkboxes & Segmented Radios
- Box width `16px` by `16px` with `2px` corners. Checked state activates full `#06B6D4` fill with void-black checkmark and high-contrast bounding halo.
